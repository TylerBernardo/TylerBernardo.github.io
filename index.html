CTF(Capture the Flag) Submission Extension

While I was taking CS261 at my local community college, I wrote 2 extensions for the proffesor to improve workflow for students in the class. I supported the JetBrains ecosystem, as well as the ReplIt online code editor. The extension zipped a student's project files and communicated with the professors server. The replit extension used js and an express server, while the JetBrains extension used Java. I am currently developing a version of the extension for Visual Studio Code. Due to the nature of this project the source code is not publicly available.

Cogitator

Cogitator is a web application for people who play tabletop wargames. The application provides statistics about different game situations to help players make better decisions in future games. The app is built with javascript, handlebars, and nodejs. A working prototype was produced, and I am currently still developing features with the goal of producing a project that would be cheap to host in Microsoft Azure.
